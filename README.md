## 🌟 قابلیت‌ها

- 🔍 **جستجوی هوشمند:** پیدا کردن فایل MP3 فقط با ارسال نام آهنگ
- 🔗 **پشتیبانی از لینک:** امکان دانلود مستقیم از لینک‌های یوتیوب
- 🎧 **کیفیت بالا:** تبدیل خودکار به فرمت MP3 با کیفیت 192kbps
- 🧹 **مدیریت حافظه:** پاکسازی خودکار فایل‌ها پس از ارسال برای جلوگیری از پر شدن سرور
- 🚀 **استقرار آسان:** آماده‌سازی کامل جهت اجرای رایگان و ۲۴ ساعته روی **Railway**

---

## 📁 ساختار فایل‌های پروژه

| نام فایل | کاربرد |
| :--- | :--- |
| `main.py` | کد اصلی ربات و منطق دریافت/ارسال موزیک |
| `requirements.txt` | پکیج‌های پایتون مورد نیاز (`pyTelegramBotAPI`, `yt-dlp`) |
| `Aptfile` | دستور نصب ابزار `ffmpeg` روی سرور Railway |
| `Procfile` | دستور اجرای پروژه در محیط Railway |

---

## 🚀 راهنمای راه‌اندازی در Railway

1. این پروژه را در حساب **GitHub** خود قرار دهید.
2. وارد **[Railway.app](https://railway.app)** شوید.
3. یک **New Project** ساخته و ریپازیتوری خود را متصل کنید.
4. در تب **Variables**، متغیر زیر را اضافه کنید:

   - **Key:** `BOT_TOKEN`
   - **Value:** `[توکن دریافت شده از BotFather]`

5. پروژه به‌صورت خودکار Build شده و ربات شما فعال می‌شود! 🎈
